다른 기기에서 이어서 볼 수 있게 정리한 기록입니다. 코드는 GitHub `Moro-I/moro-island`에 있습니다.

아임웹에는 지도 코드를 통째로 붙이지 않고, 아래만 넣으면 됩니다.

```html
<iframe
  src="https://moro-i.github.io/moro-island/"
  style="position:fixed;inset:0;width:100%;height:100%;border:0"
  title="MORO island"
></iframe>
```

## 지금까지 만든 것

- 로딩 화면은 이미지 로딩에 막히지 않고, 약 6초 뒤 CSS만으로도 닫힙니다.
- 지도는 창에 고정됩니다. 아임웹 미리보기의 검은 「디자인모드」 막대는 `preview_mode=1`일 때만 있고, 발행한 사이트에는 없습니다.
- 섬 SVG 세 장(`moro-island.svg`, `contact-island.svg`, `about-island.svg`)과 `boat.png`는 저장소에서 불러옵니다.
- 배는 커서를 따라갑니다. 아임웹 CDN 이미지는 캔버스에서 윤곽을 읽지 못했고, 지금은 같은 주소의 SVG라 섬 윤곽을 다시 읽을 수 있습니다.
- 섬 위 기호 18개를 누르면 `https://designmoro.imweb.me/work`로 이동합니다. 지도가 iframe 안에 있어도 프레임 안이 아니라 그 페이지 전체로 나갑니다.
- 기호에 마우스를 올리면 작품 게시판 첫 목록에서 고른 썸네일 18장 중 하나가 보입니다. 분류와 맞는 작품이 아니라, 기호와 이미지를 하나씩 섞어 둔 것입니다.

## 아임웹에 코드를 넣을 때 겪은 일

- 코드 위젯은 HTML, CSS, JS를 한 칸에 넣습니다. `<style>`, `<script>` 태그는 파일 안에 없고, 넣을 때 직접 감싸야 합니다.
- `styles.css`, `main.js`, `assets/` 상대 경로는 아임웹 서버에 그 파일이 없으면 열리지 않습니다.
- 로더가 끝나지 않은 이유는 두 가지였습니다. 스크립트가 실행되지 않거나, 실패한 이미지를 `waitForImage`가 끝까지 기다린 경우입니다.
- 아임웹은 SVG 업로드를 받지 않습니다. 그래서 한때 PNG로 바꿔 CDN 주소를 썼습니다. 페이지를 GitHub에 올린 뒤에는 다시 SVG로 바꿨습니다.
- 배, MORO 섬, contact 섬, about 섬 CDN 주소는 더 이상 쓰지 않습니다.

## 정해 둔 운영 방식

대표님이 직접 올리기 쉽게 하려고 아임웹을 씁니다.

- 지도는 자주 바뀌지 않으므로 GitHub 페이지의 직접 만든 화면을 씁니다.
- 작품 글쓰기와 문의 접수는 아임웹 관리자입니다. 관리자 메뉴는 **컨텐츠 관리 > 입력폼**입니다.
- 지금 GitHub의 contact 페이지는 문의하기를 눌러도 배가 움직일 뿐, 입력 내용을 어디에도 저장하지 않습니다. 아임웹 입력폼을 만들기 전에는 그 주소로 연결하지 않습니다.
- `designmoro.imweb.me/work` 연결은 실험입니다. 새 작품 페이지 주소가 생기면 섬 기호만 그 주소로 바꾸면 됩니다.
- 일상의실천(everyday-practice.com)처럼 썸네일 크기가 다른 작품 목록은 아임웹 게시판 글쓰기와 자동으로 붙지 않습니다. 그 화면은 피그마에 디자인이 있습니다. 화면을 만드는 것보다, 이미 있는 작품을 하나씩 넣는 일이 더 큽니다.
- 작품 이미지는 회사 서버에 있습니다. 그 폴더나 주소를 열 수 있게 알려주면 저장소로 옮겨 페이지를 만들 수 있습니다. 서버 위치는 아직 모릅니다.

## 도구

- 페이지를 만드는 일은 마누스, 커서, Codex가 같습니다. 만든 뒤에 글을 올리고 문의를 모아 두는 관리자는 아닙니다.
- 지금 지도처럼 화면을 보면서 고치는 일은 커서가 맞습니다. Codex는 같은 저장소를 나중에 이어서 수정할 수 있습니다. 마누스는 빈 사이트를 맡기는 쪽에 가깝고, 여백이나 호버를 하나씩 맞추는 도구는 아닙니다.
- 마누스로 만든 파일은 그 서비스 안에 생깁니다. 전체를 압축 파일로 받거나, GitHub 비공개 저장소로 보낼 수 있습니다. 코드만 받아도 문의 기록과 올린 이미지는 같이 오지 않습니다.
- 마누스는 미리 정해 둔 디자인이 없습니다. 쇼핑몰, 장바구니, 결제도 만들 수 있고 결제는 Stripe입니다. 아임웹처럼 국내 결제사, 네이버페이, 카카오페이가 기본으로 들어 있지는 않습니다.
- 이 커서 대화는 다른 기기에 자동으로 넘어가지 않습니다. 채팅은 그 컴퓨터에만 저장됩니다. 코드와 이 파일은 저장소에 있습니다.
